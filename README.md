# pcm_mix — PCM 时间线混音工具

本地节目制作用的命令行混音器：读取任务 JSON 中的 WAVE 源清单与剪辑安排，
合成一条 PCM 时间线，输出 `mix.wav` 与削波/电平报告 `report.json`。
仅使用 Go 标准库。

## 用法

```
go run ./cmd/pcm_mix 输入.json --out 输出目录
```

输入非法时以非零状态退出，且不生成任何结果文件；输出文件不会覆盖任何源文件。

## 任务文件格式

```json
{
  "sources": [{"id": "vo", "path": "vo.wav"}],
  "clips": [
    {"id": "c1", "source": "vo", "src_start": 0, "src_end": 48000,
     "out_start": 0, "gain": 0.8}
  ]
}
```

- `sources[].id` 与 `clips[].id` 分别唯一；`path` 相对任务文件所在目录解析。
- 每个片段引用一个已知源，`[src_start, src_end)` 为**左闭右开**的源帧范围，
  必须非空且不越界；`out_start` 为非负输出起始帧；`gain` 为有限浮点数，
  可为零或负数（反相），不做重采样。

## 帧与通道

- 所有索引与长度单位均为**帧**（一帧 = 每个声道各一个采样），不是单个声道采样。
- 仅接受 RIFF 小端 WAVE、格式码 1（PCM）、16 位有符号、1 或 2 声道；
  所有源的采样率与声道数必须一致。
- 未知块一律跳过，奇数字节块的补齐字节正确处理；`fmt ` 与 `data` 块各恰一个；
  截断数据或不完整采样帧会被拒绝。

## 混音与舍入口径

- 输出长度恰为最晚片段的结束帧；至少一个片段；无片段覆盖的空白帧补零。
- 各声道独立累计：按片段输入顺序，将原整数采样值乘增益后以浮点累加，
  **先求完整总和再量化**，不做逐段削波。
- 量化：四舍五入到最近整数，恰半值向远离零方向取整（0.5→1，-0.5→-1），
  再饱和到 [-32768, 32767]。

## 报告（report.json）

逐声道给出：

- `clipped_samples`：取整后超出 int16 范围的采样数；
- `peak_abs`：最终 PCM 的峰值绝对值；
- `rms`：最终 PCM 的均方根，空白帧计入分母（即除以总帧数）。
