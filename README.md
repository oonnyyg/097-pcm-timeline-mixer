# pcm-timeline-mixer

本地节目制作用的 PCM 时间线混音工具（仅 Go 标准库）。读取 WAVE 源清单与剪辑安排，
合成 `mix.wav` 并输出削波/电平报告 `report.json`。

## 用法

```
go run ./cmd/pcm_mix 输入.json --out 输出目录
```

输入非法时以非零码退出，且不生成任何结果文件；输出不会覆盖任何源文件。

## 任务文件格式

```json
{
  "sources": [
    {"id": "music", "path": "audio/theme.wav"}
  ],
  "clips": [
    {"id": "c1", "source": "music", "source_start": 0, "source_end": 48000,
     "output_start": 0, "gain": 0.8}
  ]
}
```

- `sources[].id` / `clips[].id`：分别在各自集合内唯一，非空。
- `sources[].path`：相对任务文件所在目录解析。
- `source_start` / `source_end`：以**帧**为单位的左闭右开区间 `[start, end)`，
  非负整数，必须非空且不越出源长度。
- `output_start`：非负整数帧，片段在输出时间线上的起点。
- `gain`：有限浮点增益，可为零或负数；不做重采样。

## 帧与通道

一**帧**（frame）是所有声道在同一采样时刻的一组样本；一帧的字节数 =
声道数 × 2。所有范围与偏移均以帧计，不接受单个声道样本。所有源必须采样率
与声道数一致（1 或 2 声道）。

## WAVE 约束

仅接受 RIFF 小端 WAVE、格式码 1（PCM）、16 位有符号、1 或 2 声道。
`fmt ` 与 `data` 块各恰好一个；未知块被跳过，奇数字节块的补齐字节被正确
消耗；截断数据或非完整采样帧会被拒绝。

## 混音与舍入口径

- 输出长度恰为最晚片段的结束帧；至少一个片段；无片段覆盖的空白帧补零。
- 各声道独立，按片段在清单中的顺序把 `原整数样本 × 增益` 累加为浮点总和，
  **先求完整总和再量化**，不逐段削波。
- 总和四舍五入到最近整数，恰半值向远离零方向取整（`2.5→3`，`-2.5→-3`），
  再饱和到 `[-32768, 32767]`。

## 报告（report.json）

```json
{
  "frames": 48000,
  "sample_rate": 48000,
  "channels": [
    {"clipped_samples": 12, "peak_abs": 32767, "rms": 8123.4}
  ]
}
```

- `clipped_samples`：该声道取整后超出 `[-32768, 32767]` 的采样数。
- `peak_abs`：最终 PCM 的峰值绝对值。
- `rms`：最终 PCM 的均方根；分母为全部输出帧（空白帧计入）。
